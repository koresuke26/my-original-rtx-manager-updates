My Original RTX Manager 2.9.0

このアプリはWindows用のPython版です。単体EXEではありません。

起動方法
1. ZIPを右クリックして「すべて展開」します。
2. 展開したフォルダーの中で、
   「Start My Original RTX Manager.bat」をダブルクリックします。
3. Pythonが見つからない場合は、表示された案内からPython 3をインストールします。
   インストール画面では「Add python.exe to PATH」を有効にしてください。
4. インストール後、起動用BATをもう一度ダブルクリックします。

注意
- ZIPの中から直接起動しないでください。必ずすべて展開してください。
- 「My Original RTX Manager.pyw」と「assets」フォルダーは同じ場所に置いてください。
- Pythonインストール時にTkinterを外さないでください。通常のpython.org版なら含まれています。
- Minecraftを完全に終了してから「変更をMinecraftへ適用」を実行してください。
- 現在の仕様は、！34・水透明度100%・洞窟環境光MAXです。

BATからも起動できない場合
BATをダブルクリックしたときに表示される黒い画面を閉じず、そこに表示された文章を撮影して送ってください。
その表示から、Python未導入・Tkinter不足・権限・別の実行エラーを特定できます。
